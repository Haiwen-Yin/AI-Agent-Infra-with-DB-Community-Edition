# 分版本 MCP 互操作

> 当前软件包：**川序社区版**；支持底座：**oracle, pg, yashandb**；版本类别：**Community**；许可：**Apache-2.0**。文中其他底座及企业专属能力用于说明差异，不表示此包包含或支持这些能力。

[English](mcp-versioned-interoperability.md)

端点登记选择确切协议修订。既有 `2025-06-18`、`2025-11-25` 适配器保留各自的
初始化和会话规则；独立的 `2026-07-28` 适配器支持有界 HTTP 发现与只读工具子集。
选择协议日期不会启用该协议中的全部交互。

| 交互 | 2026-07-28 适配器范围 |
|---|---|
| 发现 | `server/discover`，检查支持的版本和工具能力。 |
| 工具目录 | `tools/list`，限制元数据和 Schema 的大小。 |
| 只读调用 | `tools/call`，逐次检查当前登记、身份、暴露状态和来源权限。 |
| 结果 | 只接受 `resultType=complete`；按所支持的 Schema 子集校验声明的输出。 |
| 认证 | 每次请求重新检查登记主体及独立验证的 issuer/resource 契约。 |
| 目录缓存 | 校验并记录 `ttlMs`、`cacheScope`，仍重新读取认证结果，不跨主体共享。 |
| 不支持 | 订阅、预发布 Tasks、MRTR `input_required`、会话 ID、未登记方法；不自动回退协议或追加交互。 |

请求携带 `MCP-Protocol-Version`、`Mcp-Method`，工具调用还携带 `Mcp-Name`。
`_meta` 固定协议修订、客户端能力及客户端版本，调用方数据不能覆盖。
版本不匹配时终止当前操作，不自动尝试其他版本，也不重发结果不确定的操作。

Schema 子集限制字节数、深度、节点数和容器大小，支持常用对象、数组、标量约束
及 Boolean Schema。外部引用、正则表达式和组合 Schema 在调用前拒绝，不下载远端
Schema。MRTR 中间结果不能作为完整工具结果。

修改端点修订、URL、issuer、resource 或契约会使已有会话对象失效。重新发现仍会
使旧审批失效；缓存元数据或已知请求 ID 不保留已撤销权限。此适配器不把
Sampling、Roots、Logging 作为新增能力。

A2A 1.0.1 与 DB4A2A 继续使用各自的认证契约和 Task 连续性。兼容范围以实际
验证的交互子集为准，不将其扩展为对所有客户端、服务端、传输或扩展的兼容承诺。
