# 川序社区版 架构 v5.0.0

> 当前软件包：**川序社区版**；支持底座：**oracle, pg, yashandb**；版本类别：**Community**；许可：**Apache-2.0**。文中其他底座及企业专属能力用于说明差异，不表示此包包含或支持这些能力。

[English](architecture.md)

## 产品与数据库边界

交付注册表定义五个软件包、七个数据库验收目标。川序整合社区版包含 Oracle、PostgreSQL 和 YashanDB 适配器；OpenTenBase AgentX 是独立的 PostgreSQL 社区产品；三个川序企业版分别交付。本包支持 **oracle, pg, yashandb**，采用 **Apache-2.0** 许可。

共享业务服务只实现一次。进程在导入原生驱动前选择底座，并在整个生命周期内固定这一选择。缺失、冲突或不受支持的配置会在连接数据库前失败。更换底座需要准备独立目标并重启进程，不会自动迁移数据。产品清单决定界面、健康检查和内置知识中的产品身份；修改名称或环境变量不能启用企业专属代码。

## 数据库实体与原生适配器

数据库保存主体、组织、安全域、频道、任务计划、步骤、工作空间、分支、循环、图定义与运行、记忆版本、知识、Skill、执行尝试、租约及审计的权威事实。类型化关系、外键、唯一约束、事务检查和不可变历史共同保证操作含义。JSON 用于有界正文与协议消息，不另建一套授权或执行模型。

| 关注点 | 共享契约 | 底座职责 |
|---|---|---|
| 身份 | 已认证主体与独立 Agent 身份 | 原生 End User、LOGIN 角色或数据库用户 |
| 授权 | 当前范围、成员、授权和资源策略 | 数据库授权、行策略或受限来源投影 |
| 检索 | 授权词法/向量候选与当前来源 | Oracle Text、PG 扩展或 YashanDB 对应能力 |
| 属性图 | 实体保存事实，图只投影可见关系 | 原生图适配器与兼容 SQL |
| 部署 | 校验和绑定的有序清单与部署后验证 | 底座 SQL、前置条件与原生驱动 |
| 持久执行 | 任务/步骤、执行尝试、围栏租约与恢复核对 | 原子更新与并发行锁 |

普通业务 Agent 不能在认证失败后回退到 Schema Owner。PostgreSQL 使用非超级用户控制面 Owner、强制 RLS 和专用 Agent 角色；Oracle 与 YashanDB 使用各自的原生身份及权限边界。详见[最小权限](minimum-privileges_zh.md)。

## 人用户、Agent 与协作平面

Dashboard、Portal 会话对应人用户主体；Agent Gateway 请求对应已注册的活动 Agent 和确切实例。每次使用时复核权限版本、有效期、暂停和撤销状态。会话变更操作要求 CSRF 防护。人用户自助注册与外部 Agent 注册使用独立策略。

安全域是协作授权边界，频道是安全域内可追溯的对话入口。频道成员关系不会授予知识、记忆、工具、模型或数据库行权限。旧执行组必须具备明确的当前安全域绑定与成员资格；图边和描述性共享字段不构成授权。

注册绑定发起人、负责人、运行时、环境、安全域和准入策略。登记、凭据证明、激活、实例令牌范围及资源授权是独立步骤。平台托管业务 Agent 还需要获准模板、部署目标和通过验证的隔离环境。社区版和企业版的处理、审批差异见[运维说明](operations_zh.md)。

## 持久工作与上下文连续性

原生作业、A2A 和 DB4A2A 复用任务计划与步骤。类型化执行关系把传输层的投递、运行标识关联到同一任务根。租约与围栏拒绝过期提交，幂等键识别重复请求；无法确认是否已发送的外部请求保留为未观测状态，先核对再决定后续操作。

工作契约、责任、修订、交接、候选成果、评审及发布分别保存为数据库实体。上下文组装引用确切的已授权来源快照与摘要。派生摘要保留约束和来源关系；来源撤权后不得继续复用。交接及执行同时检查分支策略和预期版本。详见[连续性操作](continuity-operations_zh.md)与 [DB4A2A](db4a2a_zh.md)。

图工程将已发布定义编译为数据库中的运行、节点、尝试、事件和检查点。协作关卡保存参与者快照、到达记录及唯一放行决定；等待关卡时不占用 Worker 租约。循环复用有界预算和同一执行控制。离线回放与迁移预检只检查持久事实，不产生外部副作用，也不迁移正在运行的图。

## 知识、记忆与模型平面

Portal 分配符合条件的本地托管 Agent，与外部 Agent 注册无关。Portal 与频道共用授权知识检索、歧义处理和模型请求准备。检索使用人用户与 Agent 当前权限的交集，明确区分有引用回答、部分覆盖、模型通用回答及模型不可用。版本化记忆、已批准输入和连续性来源复用现有实体。

LLM 服务商配置是版本化数据库记录。模型名称和 `/v1` 地址不能证明协议或功能支持；健康检查和能力探测必须绑定确切配置修订。模型拒绝、未完整结束、流截断及混合模型响应不能作为成功能力证据。客户端断开连接也不证明服务商已经停止计算。

可选模型网关在服务端保管服务商凭据，记录有界用量、成本来源和延迟。未导入可信证据的直连调用保持未知。管理大屏只投影授权汇总，不执行操作或审批。Embedding Profile、不可变 Contract、Space 与 Binding 防止不兼容向量混入同一检索空间。

当前产品知识通过已有内置知识生命周期与公共知识实体在同一事务内发布。仅归档内容未被修改且哈希匹配的旧产品种子，保留用户编辑过的知识。

## 受控集成与隔离

MCP、A2A、遥测、工具和框架执行复用当前授权、确切契约、执行尝试、有界请求与审计。协议版本与 SDK 版本分别管理，支持范围及限制见 [Agent 扩展](agent-extensions_zh.md)。

固定 LangGraph 流程使用隔离的准备、模型调用与完成阶段；任务和恢复权威仍在平台数据库。上游发布新版本不会自动开启任意用户图、框架检查点、副作用回放、实时图迁移或全局自治修复。

控制面可以运行不代表主机具备隔离能力。原生执行还须通过主机、UID/GID、namespace、cgroup、seccomp、文件系统及出站流量门禁。未观察到基础设施适配器的实际结果时，不宣称已终止远程 Agent。详见[运行时隔离](runtime-isolation_zh.md)。

## 部署与服务边界

统一监听入口是 FastAPI `web_app:app`。React Dashboard 位于 `/app/`；Portal 和保留路由使用按请求隔离的兼容桥接，不创建第二套身份、监听器或调度器。

Bootstrap Deployment Agent 只执行包选定的 SQL，记录校验和、步骤、就绪状态及交接，不把模型文本转成 SQL 或权限。v5.0.0 保留至 `102_v5_0_0_network_access.sql` 的完整迁移链，历史 SQL 文件名保持不变。

进程重启恢复依据数据库租约及已记录结果。数据库备份、复制、备库提升和 RPO/RTO 由部署环境负责。构建或健康检查成功不等于发布验收；七个分类目标、当前包哈希和适用工作流都须验证。详见[部署](deployment_zh.md)、[迁移](migration_zh.md)与[恢复](recovery_zh.md)。
