# 产品界面规则 v5.0.1

> 当前软件包：**川序社区版**；支持底座：**oracle, pg, yashandb**；版本类别：**Community**；许可：**Apache-2.0**。文中其他底座及企业专属能力用于说明差异，不表示此包包含或支持这些能力。

[English](product-ui-guidelines.md)

规则适用于各产品中已认证的 Dashboard 页面。

## 标题与操作

页面操作使用共用 SectionHeading 区域。空间足够时刷新按钮与数据库授权标识同排；窄屏时正常换行。禁止负边距、覆盖层和相互重叠的操作控件。

## 汇总卡片

卡片按实际数量填充宽度：单卡占满、三卡等分、四卡等分。桌面共用网格为 `repeat(auto-fit, minmax(240px, 1fr))`；780 像素及以下两列，430 像素及以下一列。页面专用固定列不得预留无用空白。

## 分级标签页

桌面一级和上下文相关二级标签放在同一导航区域：完整一级组在前，二级组由可见竖线分隔并采用较小样式。二级选项不能拆开或重排一级目标。每级使用独立、允许列表内的 URL 参数，使刷新、历史、直达链接和重新登录恢复同一视图。

窄屏可整组换行，但两级不能交错、重叠或裁切标签；只有一级时不添加二级分隔线。浏览器检查中英文组边界及 URL 恢复。

## 登录与缓存

密码或 MFA 登录成功后保存会话和 CSRF 状态，再重新加载当前页面。HTML 和控制面静态资源使用 `Cache-Control: no-store`，防止升级后仍使用旧 SPA。

`/api/auth/login` 的 401 表示凭据错误或暂时锁定；已认证 API 的 401 表示登录过期。拒绝密码不能误报为会话过期。

## 流式频道消息

每个流式回答更新一个稳定消息行。类型仍为 AGENT_RESPONSE_STREAMING 时，客户端读取有界近期窗口并按消息 ID 合并；仅依赖创建时间游标无法观测原行更新。内容增长时尊重手动滚动，页面隐藏时暂停刷新，终态停止刷新。

## 平台命令与合规状态

命令目录使用抽屉可用高度，每项包含名称、本地化说明、语法、风险、执行模式和执行器状态。帮助和结果保持同一层级，明确区分创建 Action Card 与获批执行。

合规汇总卡片使用业务标题，将姿态/控制状态作为次级标签，分别说明证据评估、可见 Agent 数量和平台执行状态。正常合规、待评估、已隔离不合规使用稳定标题。移动端堆叠这些维度，说明和标签不得重叠或裁切。

## 模型路由与运营看板

模型路由位于对应 LLM 服务商配置行。直连和网关采用紧凑独立复选框，可同时开启。确认按钮同排，未修改时禁用，草稿变化时突出；保存须填写合规原因。平台生成转发地址只读，不能异常撑宽表格。

看板综合运行指标、独立 14 天 Token/费用曲线、有界用量、覆盖率与数据时效，不提供写入操作。加载、空、过期、错误和正常状态保持稳定尺寸，刷新不能推动或覆盖周围内容。

## 验证与截图

发布验证覆盖中英文、浅深主题、桌面和移动布局。截图与边界检查验证标题、操作和卡片。官网及演示材料使用当前最终包、加载完成后的实际页面，核对后端版本与实际前端资源摘要；旧版本、占位加载、错误或重叠截图不能使用。

## 页头、频道管理与主体选择

- 当前授权导航按顺序平均分两行，数量差不超过一；桌面保留在中间页头列，窄屏每行横向滚动且首项可到达。验证 2560×1600 的 100% 缩放及代表性 CSS 宽度。
- 显示运行包版本，中文品牌使用原始矢量艺术字及深色变体。
- OpenTenBase AgentX 使用 OpenTenBase 官方图形标识，旁边独立显示 `OpenTenBase AgentX`，中英文保持一致。保留图形配色和比例，登录页名称不得与主题及语言按钮重叠。
- 捐献版登录及注册页底部仅显示当前版本号，如 `v5.0.1`；页面标题和品牌标识不附加数据库版本标签。部署文档和技术配置仍说明实际支持的数据库。
- 分开讨论线程、当前成员和成员添加。短选择框顶端对齐，不能被邻近复合控件拉高。
- 复用可访问的名称/用户名组合框，保留现有受管候选接口；支持键盘、分页、同名区分、选中标签、移除和重试。仅展开时加载。
- 候选列表采用有界浮层，打开、分页和刷新均不能移动后续表单。列表内部滚动，长身份保持清楚行高。
- 提交准确选中 ID，搜索文字不满足必选要求。取消旧请求，范围改变时清除旧候选；异步成员刷新保留选择，成功提交后明确重置。

## 治理详情

普通详情抽屉最多 640 CSS 像素，知识可见范围和分支关联等密集详情采用 960 像素宽样式。780 像素及以下使用可用视口宽度，多字段行缩为单列，内容纵向滚动。输入框、选择框、文本区、按钮、面板和结构化输出必须留在抽屉内，仅隐藏横向溢出不算修复。浏览器同时检查抽屉 scrollWidth 和各控件边界。
