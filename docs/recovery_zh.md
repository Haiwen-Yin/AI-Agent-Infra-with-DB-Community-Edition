# 恢复与可用性 v5.0.0

> 当前软件包：**川序社区版**；支持底座：**oracle, pg, yashandb**；版本类别：**Community**；许可：**Apache-2.0**。文中其他底座及企业专属能力用于说明差异，不表示此包包含或支持这些能力。

[English](recovery.md)

## 状态依据

所选数据库保存任务计划/步骤、图版本/计划/运行、尝试、状态事件、检查点、租约、围栏令牌、连续性记录、投递队列及审计和治理事实。Web、Agent、Scheduler 和 Worker 不能成为这些状态的唯一持有者。

管理频道领导任期、节点升级、签名包暂存、Skill 分发、阻断和会话策略也属于持久化事实。当前租约过期后，合格替代者可取得新任期；旧领导者不能用旧围栏写入。这是基于既有数据库的应用可用性，不代表数据库集群高可用。

## 进程重启

1. 数据库不可用时停止接收新的副作用操作。
2. 重连同一已分类目标，核对身份、迁移账本、当前权限、来源摘要和能力策略。
3. 仅在相应节点与服务范围内回收已过期工作。
4. 拒绝旧围栏或过期围栏；已提交完成请求的精确重放返回原结果。
5. 从有效检查点及后续状态事件重建合法状态。
6. 仅在当前预算、租约和授权有效时恢复。

本地 Web 重启不撤销其他节点的租约。原生执行完成时必须匹配领取 Worker、节点、围栏及 CLAIMED 状态。连续性与模型请求还保留原始 Gateway 凭据、实例和上下文绑定；新令牌不能修复已撤销的原凭据。

结果不确定的模型、工具或远端操作保持 UNOBSERVED，直到核对完成。不能自动重发 NON_IDEMPOTENT 操作。只有接收服务遵守效果键合同，外部效果键才能用于去重。

## 各功能的恢复规则

| 功能 | 恢复规则 |
|---|---|
| 部署 | 恢复同一带账本计划、目标和已验证操作摘要，不猜测未知部分结构 |
| Embedding | 重试已过期且带围栏的任务；重新向量化先写新 Space，再授权切换 |
| 图 | 保留确切版本、计划、结构摘要、检查点、状态和尝试 |
| 工作连续性 | 保留不可变交接、修订、上下文及原始凭据证据 |
| 协议投递 | 只按已登记的有界策略重试，保留取消、死信和未知结果 |
| 企业版合规 | 回收已过期评估租约，保留发现项、例外身份和审计 |
| 签名升级与 Skill | 保留旧目录及 Agent 版本，直到核验安全点激活 |

DRAINING 节点保留有界活动工作，拒绝新领取；相关工作排空前不能进入 MIGRATING。缺少 Skill 确认属于偏差，不允许强制切换正在运行的回合。协作式 Skill 包装器不能隔离绕过它的进程。

过期合规证据只降低治理状态，不能自动隔离或恢复权限。被隔离 Agent 按治理修复路径恢复，并保留触发的发现项。系统 Agent 身份不能用于恢复人用户或 Schema Owner 凭据。

## 备份与升级

修改既有数据库前，保留配套且经过恢复验证的数据库备份、私有配置、加密密钥、部署账本和确切程序包。运维确认此恢复边界，客户端参数不代表验证了备份。详见[迁移](migration_zh.md)。

只排空受影响的写入类型。Oracle 任务迁移保留可恢复复制、检查和切换阶段，不扩大为全平台停写。失败时保留账本、旧文件与数据库恢复事实；恢复已验证计划，或按获批数据库恢复流程处理。

程序回滚必须匹配已恢复的数据库/结构及支持的产品和版本类别，不能默认把历史 v4.1 配置运行在当前结构上。数据库转换、跨产品更名、凭据轮换及不可逆外部效果须有独立明确的恢复计划。

## 数据库可用性

数据库复制、存储持久性、备份与故障切换由部署方负责，须选择对应数据库认可的高可用方案并在目标环境验证。进程替换测试不能证明备库提升、集群切换、RPO 或 RTO。

客户完成数据库切换后，应用重新连接并核对目标身份、账本、无效对象、授权、租约和图就绪状态，再恢复流量。数据库不可用或无法恢复时，不能以内存权限状态替代。

## 制品与证据完整性

按内容寻址的制品保留分类、保留期和法律保留。正文不可用时保留摘要与状态迁移元数据，报告缺失，不能静默换成其他字节。法律保留阻止清除。支持导出只包含脱敏、有界证据，不包含凭据或完整配置。详见[发布签名](release-signing_zh.md)和[连续性操作](continuity-operations_zh.md)。
