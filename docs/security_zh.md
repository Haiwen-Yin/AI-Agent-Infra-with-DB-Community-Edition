# 安全契约 v5.0.0

> 当前软件包：**川序社区版**；支持底座：**oracle, pg, yashandb**；版本类别：**Community**；许可：**Apache-2.0**。文中其他底座及企业专属能力用于说明差异，不表示此包包含或支持这些能力。

[English](security.md)

## 身份与数据库权限

本包支持 **oracle, pg, yashandb**，提供 **Community** 功能。身份、授权、能力状态、执行尝试、
租约和审计均以数据库记录为准。模型文本、Skill、图边、URL、框架回调、客户端填写的
Agent ID 和页面按钮都不授予权限。

Human 用户、平台 Agent、外部 Agent 与 Schema Owner 是不同身份。停用、撤销、过期、
未知或凭据不匹配的身份一律拒绝访问。普通业务 Agent 使用独立原生身份，不回退到 Owner
凭据。配置和加密私钥只允许运行账户读取。

PostgreSQL 使用独立 LOGIN 角色、可信身份映射和强制 RLS，客户端设置的会话文本不能覆盖
角色映射。受约束的可信 Owner 策略解析每张表的真实所有者，普通 Agent 不能成为 Owner
成员。Oracle 使用原生 End User、上下文和数据授权边界。YashanDB 使用自身用户、对象授权
和受限投影。必须通过原生拒绝测试证明覆盖，不能从服务端过滤推断数据库安全。参见
[最小权限](minimum-privileges_zh.md)。

## 认证、注册与会话

首次初始化需要部署专用管理员密码，按现有策略至少 12 位，仅保存 Argon2id 哈希，没有
通用默认密码。非交互输入使用当前用户拥有、权限为 0600 或更严格的普通文件。明文不能
出现在命令参数、账本、证据或公开配置中。

人用户自助注册和外部 Agent 注册分别配置。关闭人用户注册入口不会关闭 Agent Enrollment。
Agent 注册需要有权限的发起人、限定范围的授权、凭据证明和激活。一次性兼容客户端秘密或
Ed25519 证明用于换取短期实例令牌。令牌保留精确作用域、实例围栏和当前权限；完成注册
不自动获得模型、Embedding、工具或数据访问权。

Dashboard 与 Portal 使用独立且按端口区分的会话 Cookie。已认证的变更操作要求绑定会话的
CSRF 令牌，并核对数据库状态、权限修订和撤销情况。浏览器存储、请求正文中的 ID 和过期
权限缓存不能证明身份。

## 组织、安全域与频道

组织描述责任与知识范围；安全域规定协作授权边界；频道承载对话。列表、消息、历史、线程、
Gateway 准入和工作操作都检查当前成员资格。暂停或撤销成员关系会阻止后续访问，但保留历史。

频道成员不自动获得知识、记忆、工具、模型、导出或数据库行权限。历史执行组要求显式有效
安全域绑定及当前参与者检查。转换草稿只列出候选，不授予成员资格。跨域转移需要明确的
Bridge 策略与密级检查。

知识列表、单项、图和检索一致执行公司公开、组织子树、组织层级或主体私有策略。Portal
与频道取 Human 和 Agent 授权的交集。含糊的厂商或产品问题需要相关性判断或澄清；无关
产品文档不能仅凭某个关键词匹配就成为回答依据。

## 模型、Embedding 与不可信输入

模型服务商密钥在服务端加密保存，读取时脱敏。可选模型网关记录请求元数据、摘要、用量
来源、费用与延迟，不记录提示词、生成正文、授权头或隐藏推理。直连流量没有经过核验的
导入证据时属于未观测。运营看板仅提供有数量限制、经过授权的只读投影。

健康与能力证据绑定模型配置的精确修订。拒绝、不完整完成、无效格式、截断流或混合模型
分块都不能证明能力通过。关闭客户端连接不等于远程模型服务已停止计算。

Embedding 契约固定模型、维度、度量、归一化、预处理、模态和来源模式。写入与检索使用
当前有效 Space/Binding，不兼容契约不能共用相似度计算。外部 Agent 需要显式授权和限定
范围的 Gateway 令牌，不接收模型服务商密钥。缺少授权或存在显式拒绝时停止访问。

上传文档、图片、检索知识和远程协议输出都属于不可信数据，不能授权工具或改写安全策略。
受管输入要求数量和大小限制、作用范围、可撤销性及来源摘要检查。知识正文保留与不存正文
的用量、遥测记账是两种不同机制。

## 工作、副作用与协议边界

Task/Step、Graph、Loop 和连续性操作检查当前归属、安全域、预期版本、来源链、预算及
策略。执行尝试使用会过期的租约和围栏；被替换的旧 Worker 不能继续提交。要求原子性的
操作在同一事务中提交状态和审计。

A2A 与 DB4A2A 共用类型化任务标识，保留独立传输路径。引用和摘要不会授予接收方访问权。
创建和重试都核对原始发送方、接收方、来源快照及当前策略。未观测的外部结果需要核对，
盲目重试不能保证副作用只发生一次。

MCP 发现不代表批准执行。只有精确匹配已批准只读工具契约的请求可经受控路径执行。
重新发现后原批准失效，必须再次审核。远程端点需要登记协议、版本、域、专用凭据、限制
和当前授权。遥测发送已提交元数据，不含提示词或输出正文。

固定框架执行要求摘要锁定的依赖集合与已验证的不可变根文件系统。任意框架、副作用回放、
动态图在线迁移和全局自主修复保持关闭。支持范围见[Agent 扩展](agent-extensions_zh.md)。

## 主机隔离与运维

控制面能启动不等于主机能安全运行不可信 Agent。运行目标必须通过 UID/GID、namespace、
cgroup v2、seccomp、只读根文件系统、能力集、挂载与出站检查。Agent 状态不能覆盖模板
最低隔离要求。共享 Worker 不能在 Agent 间复用凭据、工作区、对话状态或数据库会话。

紧急阻断撤销实例令牌，并分别报告每项动作结果。远程进程终止需要基础设施适配器返回
真实执行结果，协作式确认不证明操作系统进程已终止。维护排空与安全事件阻断分别处理。

Bootstrap Deployment Agent 仅执行本地校验和绑定的清单。LLM 输出不能选择 SQL、权限
或部署转换。已有数据升级需要明确数据库恢复边界。替换程序时保留加密密钥、配置和私有
账本。数据库复制、备份与主备切换由部署方负责。

## 企业版边界

社区包物理裁剪企业审批、合规、审计查看及其他专属模块，仍保留强制审计写入。企业版
增加分级资源策略、分离审批、合规证据、保留与法律保全及限定范围的证据导出。

合规 Agent 提出并记录整改，不继承平台管理权限。管理对话用于建议；类型化命令仍受
风险策略、当前权限和相应人工审批约束。高影响决定不能从模型输出中获得授权。

运维检查参见[发布验证](release-signing_zh.md)、[恢复](recovery_zh.md)和
[运行隔离](runtime-isolation_zh.md)。发布测试不等于独立安全审计，也不保证任意环境的
隔离、容量或特定客户合规认证。
## 来源 IP 限制

所有产品都支持在平台配置中设置 IPv4 / IPv6 白名单或黑名单，覆盖全部 Web 入口，受限来源返回通用错误。
保留 `127.0.0.1` 直连应急访问，仍须正常登录。配置、代理信任和恢复方法见[访问 IP 限制](source-ip-access_zh.md)。
