# 平台学习知识的交付与导入

> 当前软件包：**川序社区版**；支持底座：**oracle, pg, yashandb**；版本类别：**Community**；许可：**Apache-2.0**。文中其他底座及企业专属能力用于说明差异，不表示此包包含或支持这些能力。

平台学习入口位于 Dashboard 的知识页面，也可以从连续性工作台打开。知识库的
创建、检索与权限功能可独立使用；没有平台学习资料不会影响平台启动。

外部 Agent 使用自身含 `knowledge.read` 的 Bearer 令牌调用
`GET /api/agent-gateway/continuity/learning?role=AGENT`，再按 ID 和摘要读取
精确章节，无需加入频道。完整流程与授权排错见
[外部 Agent 读取平台知识](external-agent-knowledge_zh.md)。

社区版与 OpenTenBase AgentX 的软件包不包含 v5.0.3 新增的九个完整平台学习
单元，安装时只发布原有四类简要产品说明。完整学习内容作为独立 JSON 文件
放在交付目录的 `knowledge_packages/`，不在软件压缩包内，也不会自动导入。
企业版保留完整内容及安装时的自动发布。

有需要时，由当前具有 `platform.manage` 权限的管理员登录 Dashboard，打开
知识页面的“平台学习指南”，选择对应产品和软件版本的独立 JSON 文件，再点击
“导入并发布指南”。文件选择本身不发布内容。服务器依据软件中的摘要引用检查
当前产品、软件版本、数据库与完整内容；整合社区版只导入当前选择的数据库资料。
不匹配或被修改的内容会被拒绝。此检查验证与软件交付的一致性，不代表外部发行者
的密码学签名认证。

导入成功后，资料通过既有数据库知识实体和受信内置包机制发布。使用者按角色和
目标发现目录，按精确摘要读取章节；读指南不会执行操作或授予权限。重复导入相同
内容不新增重复实体。撤回沿用平台内置知识包的现有撤回 API，并同时停用未经用户
修改的知识投影；撤回的同一快照不能再次发布。

升级到独立交付策略时，平台保留数据库中已经安装的学习知识、历史快照和用户
补充，不自动删除或用简要说明覆盖。未导入适用资料时，学习入口显示空状态。
客户自建知识继续使用原有访问范围与治理流程。
