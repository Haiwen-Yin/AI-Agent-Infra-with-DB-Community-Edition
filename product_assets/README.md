# OpenTenBase AgentX brand assets / 品牌资源

OpenTenBase AgentX uses the official OpenTenBase emblem beside the separate
product name `OpenTenBase AgentX` in both languages. The emblem retains its
original colors and geometry in light and dark themes.

- `opentenbase-logo.png` is the supplied upstream OpenTenBase logo, unchanged.
- `opentenbase-mark.png` extracts the colored emblem at pixel bounds
  `(0, 498, 386, 754)` from that source. Only the surrounding transparent canvas
  and the upstream wordmark are excluded; no emblem pixels are redrawn.
- Upstream: <https://www.opentenbase.org/>
- Source SHA-256: `99974c71809e1be8a18dac5974fef65a88041e7ffc43cd0dd5e1da5f39d71533`.

OpenTenBase AgentX 的页面使用 OpenTenBase 官方图形标识，旁边独立显示
`OpenTenBase AgentX`，中英文名称一致。浅色和深色主题均保留图形原有配色及比例。
原始图片完整保留；页面资源仅提取其中的彩色图形，移除透明留白及原图文字，
不重绘图形，不在图形中添加产品名称。
